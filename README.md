# Тестовое задание: расчёт авансов и взаиморасчётов по договорам

Программа рассчитывает состояние взаиморасчётов по работам и договорам с подрядчиками на любую заданную дату с автоматическим распределением авансов по методу FIFO (с приоритетом фактически завершённых работ).

## Требования
* Python 3.10+
* Стандартная библиотека (сторонние зависимости не требуются).

## Запуск

### 1. Формирование отчёта на контрольную дату (10.11.2026)
```bash
python3 solution.py --date 2026-11-10
```

### 2. Экспорт отчёта в CSV файлы
```bash
python3 solution.py --date 2026-11-10 --csv-out reports/
```
В директории `reports/` будут созданы:
* `report_works_2026-11-10.csv` — детализация по каждой работе (цена, оплачено, остаток, статус).
* `report_contracts_2026-11-10.csv` — сводные итоги по каждому договору.

### 3. Запуск тестов
```bash
python3 -m unittest discover tests
```

## Структура проекта
* `solution.py` — точка входа CLI.
* `src/models.py` — строго типизированные dataclass-модели (`Decimal`, `date`).
* `src/loader.py` — чтение и парсинг CSV файлов.
* `src/calculator.py` — бизнес-логика исторического среза и FIFO-распределения оплат.
* `src/reporter.py` — форматирование консольного вывода и экспорт в CSV.
* `candidate-B/DECISIONS.md` — детальное описание всех принятых решений и развилок.
* `candidate-B/NOTE_FOR_ACCOUNTANT.md` — краткая записка бухгалтеру (5–10 строк).
* `docs/UML.md` — UML-диаграмма классов и схема пайплайна (Mermaid).
* `transcript.md` — полный экспорт сессии диалога командой `/export`.
* `session.jsonl` — полный машинный JSONL-журнал сессии Claude Code.
